# nl2sh

Android Shell AI Agent，支持 TUI 与 Web。首次运行 `nl2sh`，使用 `/config` 配置模型；通过 `pkg upgrade nl2sh` 更新。

- [中文文档](https://nl2sh.github.io/nl2sh/)
- [Termux 安装与使用](https://nl2sh.github.io/nl2sh/getting-started/termux/)
- [English](README_EN.md)

默认 Web 无登录且监听所有 IPv4，请只在信任网络使用。修改/危险操作须按本地风险确认。
