# nl2sh

Android Shell AI Agent with TUI and Web. Run `nl2sh` and configure a model with `/config`; update with `pkg upgrade nl2sh`.

- [English documentation](https://nl2sh.github.io/nl2sh/en/)
- [Termux installation and usage](https://nl2sh.github.io/nl2sh/en/getting-started/termux/)
- [简体中文](README.md)

Web has no login and listens on all IPv4 interfaces; use trusted networks. Mutations/dangerous actions retain local risk-based approval.
