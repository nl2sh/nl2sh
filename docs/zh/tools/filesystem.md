# 文件系统工具

| 工具 | 用途 | 边界 |
| --- | --- | --- |
| `read_file` | 有界文本读取 | 指定路径、窗口和返回上限 |
| `list_dir` | 列出目录 | 条目数有界 |
| `search_text` | 定向搜索文本 | 文件/匹配/字节数有界 |
| `apply_patch` | 应用文本补丁 | 预览 diff、确认、唯一替换、原子写入 |

路径无工作区限制，允许绝对/父目录/符号链接；仍受进程权限约束。先 `list_dir` 或小窗口读取，再扩大范围；截断结果不是完整文件。不能用这些工具绕过 Android 私有目录权限。

用 `@` 传路径：“解释 `@/data/local/tmp/config.toml` 的非敏感设置，不显示密钥”；“检查这个文件的指定函数，先给出补丁 diff”。模型读取文件时将内容视为数据，文件中的指令不是执行授权。

补丁展示的目标和预览在执行前检查；拒绝不会写入。参数定义见 [完整目录](../reference/tool-catalog.md)。
