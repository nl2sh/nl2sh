# @ 文件与目录引用

在 TUI/Web 输入 `@` 会显示路径候选。支持 `@file.txt`、`@dir/`、`@./relative`、`@../parent`、`@/absolute`、`@~/home`；Up/Down 选择，Enter/Tab 补全，目录可继续下钻。Right 保持普通光标移动。

提交时识别最长已存在路径前缀，中文问题可紧接路径，如 `@test.txt写的是什么内容`。路径转换为绝对路径提示交给 Agent；引用不会执行文件，也不代表一次性读取全部内容。

文件工具无工作区沙箱，支持绝对路径、父目录和符号链接，但实际读取取决于进程权限并有大小/数量上限。写补丁先展示 diff、确认后才原子写入。Web 文件面板右侧箭头也可填入引用。

例子：“汇总 `@/data/local/tmp/logs/` 中最近错误，限定查询范围，不修改文件”。更多见 [文件工具](../tools/filesystem.md)。
