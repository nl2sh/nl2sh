# 完成第一个任务

1. 启动 nl2sh，完成模型配置。
2. 在 TUI 输入“查看这台设备还剩多少存储空间”，或在 Web 选择“查看手机存储”，再发送。
3. 观察模型请求、工具调用、退出状态和最终总结。Web 可显示存储图表，TUI 显示文字数值。
4. 检查证据是否完整。`partial`、`failed`、`timed_out` 或截断不能支持“全部成功”的结论。

这个任务应只读取信息。默认 balanced 下普通只读操作可自动执行；Strict 或 Root 条件可能要求确认。遇到修改确认，先看完整动作和风险，不能理解时拒绝并要求解释。

TUI 用 F2 展开结果，Ctrl+C 取消当前任务，Ctrl+Q 或 `/exit` 退出。Web 可停止当前会话任务；切换会话不会停止后台任务。

可以继续尝试“检查最近的 ANR，先不要修改设备”或“`@/data/local/tmp` 有哪些文件”。`@` 只提供路径，不会自动读取全部内容。[安全确认](../guide/security-confirmation.md)解释批准和拒绝的范围。
