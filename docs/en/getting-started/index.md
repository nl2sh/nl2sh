# Getting started

Follow four steps; no Rust or tool-protocol knowledge is required.

1. [Choose an installation](installation.md): ADB from a computer or Termux on Android.
2. [Connect Android](android-adb.md), or [install a Termux package](termux.md).
3. [Configure a provider](configure-provider.md): service URL, model name, and API key.
4. [Run a read-only task](first-task.md) and learn how results and approvals work.

nl2sh is an Android API 26+ shell executable, not a chat APK. The optional companion APK provides system interaction only. Full UI automation requires shell/root UID; ordinary Termux UID lacks these permissions.
